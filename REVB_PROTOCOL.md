## Exact KT and startup

Use a separate order-k full context consisting of the previous k bytes, latest first. At zero-based position i, for k<=i score from exact past full-context counts using `-std::log2((double(count)+0.5)/(double(total)+double(S)/2.0))`; an empty row costs exactly log2(S), i.e. 5.0 or 8.0. For i<k add exactly log2(S) for that order and **do not update any shorter full-context row on that order's behalf**. Equivalently each unavailable-history event has a once-only order/length-tagged startup context. Update the genuine rows of depths 0..min(i,K) only after all orders have scored. No reset at file chunks, checkpoints, sentences, words, documents, or generator block boundaries; initial history is empty, not artificial zero padding.

Per-order L uses input-ordered binary64 addition, no fast-math, reassociation, Kahan replacement, offline gamma totals, or parallel reduction. A(k,n)=(L(0,n)-L(k,n))/n, with A(0,n)=+0.0. Preserve negative A and signed denominators. Snapshot after scoring/updating the nth symbol; counts and cumulative losses include that symbol. All k and checkpoints share one corpus pass and continuous state. Distinct-depth rows may share a compressed-edge representation only under DESIGN.md's exact event-set invariant, not backoff.

## Track A kernels and complete randomness consumption

Reuse `design/prng_reference.hpp` verbatim, SHA256 `a38ce3bd9dbf751f40b92c5ebea85c191e60c71d935b134068944651582b7542`: SplitMix64 state=uint64(seed), no warmup/name hashing, unsigned wraparound, rejection-based `uniform(b)` as in that file. Each configuration/seed starts a fresh PRNG. Bounds used are 4,8,16,32; their rejection thresholds are zero. Stop exactly at N; no extra block completion, unused emitted symbols, or initial draws beyond what the stream needs. Analytical entropy refers to ideal stochastic kernels, not the entropy of a fixed deterministic seed.

**Lag-copy(d):** positions i<d each consume one `uniform(32)` and emit it. Every later position consumes first `uniform(4)` then `uniform(32)`, including on copy events. Coin 0,1,2 emits x[i-d]; coin 3 emits the innovation. Initial d bytes are independent uniform in the ideal process; maintain a bounded d-byte lag ring. G1 uses d=1; G2 uses d=5. For each paired distance d in `[4,8,12]`, G5(d) uses short lag **2**, and G6(d) uses lag **d**. Thus G5(4), G5(8), G5(12) with the same seed intentionally produce identical bytes, but are retained as three registered pair identities; they are not independent replications across d.

**G4:** consume one `uniform(32)` per byte and emit it. Its theoretical unigram is exactly G2's uniform stationary marginal, not a finite-sample fitted histogram.

**G3(d)** for d in `[2,3,4,5,6,8,10,12,14]`: fixed blocks of length **d+1**, first block starts at i=0, no phase randomization or warmup. At phase 0 consume `uniform(8)` and emit/store controller `16+draw` (16..23). At phases 1..d-1 consume `uniform(16)` once each and emit filler (0..15). At phase d emit stored controller+8 (24..31), consuming no draw. Agreement is precisely lag d. Truncated last block stays truncated.

**Analytical checks, not predictions fitted to data:** Lag-copy has uniform stationary marginal and conditional probabilities q=97/128 for its lag symbol, r=1/128 for each other symbol. Its entropy rate is `-q log2(q)-31 r log2(r)=1.9985035492800673` bits/symbol for every d. Independent stationary residue chains imply conditional entropy 5 below lag d and this h at/above d. Paired G5/G6 entropy difference is exactly zero, within 0.02. G4 entropy is 5. G3 independent block entropy is `3+4(d-1)=4d-1`; rate `(4d-1)/(d+1)` bits/symbol, with bounded startup/truncation correction. Fixed phase and disjoint types create shorter-range phase information: G3 is not a stationary pure-lag source. The Rev A exclusion of k=1 from a dominance comparison is **not** retained: Rev B prediction 3 compares every increment k=1..16. Finite-N sparse-context or phase-driven failure is evidence to report, not permission to modify a kernel.

## Aggregation, arithmetic, and undefined values

For each named configuration/corpus compute its arithmetic mean surface over its five seeds/draws **before** between-configuration comparisons, normalization, increments, or ridge evaluation. Use registered seed order and B draw order 1..5 for deterministic binary64 sums, divide by 5. Preserve each individual surface and diagnostics. Report pointwise sample standard deviation `sqrt(sum((A_r-mean_A)^2)/4)` in the same order; this is spread, not a confidence interval. Do not pool G5 identities or different G3 distances. Compute seed-level descriptive diagnostics additionally; their means do not replace diagnostics computed from the mean surface.

All strict inequalities use the actual saved binary64-derived values, with no rounding before decisions or epsilon/tolerance for gates. A unique maximum means strictly greater than **every** other compared value; any exact tie for the largest increment fails uniqueness. Numerical correctness-test tolerances do not change gates. Save enough precision for roundtrip (17 significant digits) and bit-pattern hex for raw L/A. Preserve intermediate witnesses, denominators, extremizing indices (lexicographic first index for display only), and all individual-run checks.

Any zero denominator (+0 or -0) is undefined, including 0/0 and positive/0. Represent undefined as JSON null plus reason and check status `undefined`, never Infinity/NaN or a replacement epsilon. A predicate requiring an undefined quantity is not passed. Missing/incomplete inputs instead make checks `incomplete` and yield no completed scientific verdict. Negative nonzero normalization denominators are used unchanged and reported; tiny nonzero denominators receive no stabilization. Distances take absolute differences, not absolute denominators.

## Ten frozen predictions

Write M_g(k,n) for the five-run mean, Delta_g(k,n)=M_g(k,n)-M_g(k-1,n), k=1..16, and D(U,V)=max over all registered k,n of |U-V|. Unless specified, use n=2^23.

1. G1: Delta(2)<0.01.
2. G2: Delta(6)<0.01 **and** Delta(5)>0.05.
3. Every G3(d): Delta(d)>0.05 and Delta(d)>Delta(k) for **every** k in 1..16 except d. All nine d must pass; ties fail.
4. G4: M(k)<0.01 for every k=1..16. Negative values stay negative; this is a one-sided bound, not absolute closeness to zero.
5. For each paired d=4,8,12, max over k=0..16 of |M_G5(d)(k)-M_G6(d)(k)|>0.1. All three pairs must pass. This is the full-n curve comparison, not an opportunistic maximum over n.
6. **Explicit operational convention for saturation:** R_g(n) is the **first** k in 1..16 for which Delta_g(k,n)<0.01. If none exists use ordered sentinel 17, labeled `right_censored_above_16`, not an observed threshold at 17. Prediction 6 requires G2's operational R to be nondecreasing over the 12 checkpoints and R(2^14)<R(2^23). Compare the frozen ordinal sentinel normally (equal sentinel values do not meet strict inequality). This deliberately resolves Rev B's undefined saturation using Annex's first-below cutoff. It is **not sustained plateau saturation**, can precede later peaks, and has no automatic plateau interpretation. Save both integer category and censor flag; the Annex ridge uses this same rule, without new gates.
7. G6(12): M(k,n)<0.3 for every k=0..16 at n in `[2^12,2^13,2^14,2^15,2^16]`.
8. Eligible g = G1,G2,G3(8),G5(8),G6(8). Divide each **whole mean surface** by its own M_g(16,2^23), then require the maximum of the ten pairwise D distances >0.15. No averaging already-normalized seeds. Any required zero denominator makes this check undefined. Report signs and small-denominator amplification.
9. Track B only: numerator=max over the ten corpus pairs D(M_Bi,M_Bj); denominator=max over all B1..B5 and all ten distinct within-corpus draw pairs D(A_Bi,r,A_Bi,s). Require numerator/denominator>3. Exactly 3 fails; zero denominator is undefined, not perfect usefulness. Shared B1/B4/B5 provenance is disclosed, not treated as independent corpora.
10. Track B: M_B1(k)>M_B4(k)>M_B5(k) for every k=4..16 at full n. Ties fail.

Compute and publish three gate checks independently, including every constituent numeric check even when another gate fails: Correctness={1,2,3,4,6,7}; Foundation={5,8}; Usefulness={9,10}. ## Gated separability

Run on all nine G3(d), all five seeds, at all k/checkpoints, **only if Correctness and Foundation pass** (Usefulness need not pass). Apply these global maps to the already-registered bytes; no new random draws:

- Within-class: for x=0..15, pi(x)=(x+1) mod 16; x=16..23 maps to 16+((x-16+1) mod 8); x=24..31 maps to 24+((x-24+1) mod 8).
- Across-class: exchange x=j and x=16+j for j=0..7; leave 8..15 and 24..31 fixed. This is an actual global bijection, not corruption or a context-dependent map.

Within-class requires absolute A difference <0.01 at every cell of every paired individual surface; report raw deltas and means. Across-class report signed original-minus-permuted deltas at/above k=d and all other cells, without inventing a numeric threshold for the unspecified 'measurably'. Symmetric KT is exactly invariant to **every** global bijection (contexts and count categories are bijected, totals/half-counts unchanged). Thus the requested across-class drop is mathematically impossible; report that contradiction/failure rather than modifying the map or estimator. Production permutations are secondary surfaces, not part of the 90 primary runs.

## Annex A instrumentation (non-confirmatory)

These observables have no power to alter any gate or justify reruns/tuning.

1. **Increments and n finite differences:** per run and on the mean surface save Delta(k,n)=A(k,n)-A(k-1,n), k=1..16. On adjacent checkpoints n_j,n_{j+1}, save `[Delta(k,n_{j+1})-Delta(k,n_j)]/(n_{j+1}-n_j)` located on that interval, units bits/symbol per added input symbol; delta-k is one. This is a forward difference in **linear n**, not log2(n). Endpoints outside the grid are unavailable; do not invent central/interpolated values. Also save the first-below ridge/censor categories above.
2. **Occupancy at each checkpoint, per order:** use genuine full-order context rows with total T_c>0 **after** n updates. E_k=max(n-k,0) is full-context visitation count. Save distinct count D_k, singleton-context count, count of contexts with 1<=T_c<5, singleton visitation numerator sum(T_c 1[T_c=1]), and rare visitation numerator sum(T_c 1[1<=T_c<5]). Masses divide the latter two by E_k; E_k=0 is undefined. Exclude once-only startup contexts and unvisited rows. Logical contexts inside compressed edges count once at each represented depth, not once per physical node. These are **empirical visitation masses**, not true generator probability mass or held-out probability.
3. **Checkpoint conditional ML reference:** declare retrospective, unsmoothed conditional maximum-likelihood checkpoint code functional `L_ML(k,n)=min(k,n)*log2(S) + sum_c [T_c log2(T_c)-sum_a C_c(a) log2(C_c(a))]`, over full-order rows; 0 log2(0)=0. Keep the same fixed uniform startup contribution as KT for comparability. This is feasible incrementally from exact pre-update counts: for a full-context event add `g(T)-g(C_x)` to its order's ML accumulator, where `g(t)=f(t+1)-f(t)` and `f(t)=double(t)*log2(double(t))`, f(0)=f(1)=0; evaluate g(T) then g(C_x), subtract, then add in input order. Startup adds exactly log2(S). Reuse identical row deltas across an edge, but add separately per order. ML finite-precision recurrence is declared, not promised bit-identical to a post-hoc sum. Validate it against direct finite-fixture checkpoint counts within stated test tolerances. This reference is a hindsight fitted-data length, not a normalized online/universal code including parameter transmission. Save L_ML, `L_KT-L_ML`, and `(L_KT-L_ML)/n`. Label the latter two **KT-minus-ML descriptive redundancy**, NOT uniquely pure learning/estimation cost. This subtraction depends on reference and startup; do not claim identifiability. If instrumentation cannot be delivered, flag the observable unavailable before the run, not silently substitute another reference or reconstruct it from L alone.
4. **Track A predicted-symbol decomposition:** ordered per-(k,a) accumulation of each loss with predicted byte x_i=a, including startup. Save count N_a and L_k,a at every checkpoint; contribution A_a(k,n)=(L_0,a-L_k,a)/n, zero when N_a=0. Contributions sum to total A mathematically (separate binary64 accumulation can differ slightly; report residual rather than forcing equality). Optional within-symbol average uses N_a and is undefined at zero. Type totals for G3 sum the fixed filler/controller/agreement sets. This is attribution by predicted symbol, not conditioning the estimator on type.
5. **Track B whitespace alignment:** scoring-only byte mask W={9,10,11,12,13,32} (ASCII whitespace); no Unicode whitespace inference or tokenization change. No model reset. Each event is assigned one of three disjoint buckets: `whitespace` if current byte is in W; `token_first` if non-W and (i=0 or previous byte in W); otherwise `token_continuation`. At each checkpoint save bucket counts and ordered L_k,bucket; contribution `(L_0,bucket-L_k,bucket)/n`, optional per-bucket conditional average with count denominator. Separately maintain the latest cumulative L snapshot **ending immediately after any whitespace byte**; b(n) is that byte's 1-based offset <=n. Save b(n) and aligned A(k,b)=(L_0(b)-L_k(b))/b. If no whitespace exists, aligned values/offset are null. A whitespace run may supply several eligible boundaries; the last byte seen wins, even if n cuts the run. Bytes after b are excluded only from this aligned snapshot, never from raw A(k,n). Do not read ahead to complete a token/run or move n. This is explicitly byte-whitespace-aligned prefix availability, not an average word-level availability, sentence alignment, or a substitute for raw gates. B4/B5 transformations must preserve their parent B1 byte count/multiset under Sonnet's separately frozen segmentation/whitespace policy; this scoring mask does not prescribe that segmentation.
6. Persist per-run raw checkpoint L/A, ML reference, occupancy numerators/denominators, attribution arrays, mean surfaces, sample standard deviations, individual diagnostics, and derived finite differences. Later reporting reads saved arrays; it does not regenerate/re-score corpora to recover missing diagnostics. Record unavailable fields with reasons.
